# skills

Skills served as tools by [skills-mcp](https://github.com/harsig/skills-mcp). Each folder holds one `SKILL.md`; see the skills-mcp README for the format.

| Skill | Purpose |
| --- | --- |
| `date-output` | Adds 5 minutes to every time the agent states. The shift is deliberate and easy to spot, so you can tell from an answer whether the agent loaded the skill. |
